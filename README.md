# Invitación M&A

Sitio estático (sin build). Todo vive en `public/`.

## Publicar en Vercel
Opción A (sin instalar nada): entra a https://vercel.com/new, elige "Deploy" arrastrando esta carpeta, o súbela a un repositorio de GitHub e impórtalo. Framework preset: "Other". No requiere build command.

Opción B (terminal):
    npm i -g vercel
    cd boda-ma-vercel
    vercel --prod
